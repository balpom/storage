# balpom/storage
## Simple abstract storage for abstract data storing.

Abstract data abstract storage.
Consist simple realisation for "key-value" data storing in local files and memory, implemented via the appropriate drivers.

### Requirements 
- **PHP >= 8.2**

### Installation
#### Using composer (recommended)
```bash
composer require balpom/storage
```
